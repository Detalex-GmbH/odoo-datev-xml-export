DATEV XML Export

Advanced XML Export for German Accounting Compliance

This module provides advanced functionality for exporting invoices and bills to the German DATEV system using the modern XML interface format with full support for digitized receipts.

Key Features

Complete DATEV XML Export

Export invoices and bills directly to DATEV in modern XML format with full validation support.

Digitized Receipt Handling

Attach and process digitized receipt attachments with automatic PDF merging for multiple documents.

Flexible Export Options

Choose between time-based batch exports or individual document exports with tracking.

DATEV Validation

Comprehensive validation with error handling and magic button integration for quick resolution.

GDPR Compliant

Data handling complies with GDPR requirements and German data protection standards.

GoBD Ready

Meets German accounting compliance standards (GoBD - Grundsätze ordnungsmäßiger Buchführung).

Technical Capabilities

  • XML/ZIP Generation: Automatic generation of DATEV-compliant XML files with ZIP packaging
  • XSD Validation: Built-in schema validation to ensure DATEV compatibility
  • PDF Processing: Intelligent attachment handling and PDF merging for multiple receipts
  • Export Tracking: Comprehensive logging and history of all export operations
  • Error Management: Detailed error reporting with actionable resolution steps
  • Integration: Seamless integration with DATEV Unternehmen Online platform
  • Magic Button: Quick-access interface for exported invoice navigation and validation

About DATEV

DATEV is the leading accounting software platform in Germany, Austria, and Switzerland, used by over 500,000 accounting firms, tax advisors, and companies for comprehensive accounting and tax services. The XML export format is the modern standard for data transfer to DATEV systems, replacing legacy ASCII-based formats with improved validation and enhanced receipt handling.

System Requirements

Software Requirements:

  • Odoo 18.0 or later
  • Base DATEV Export module (dtx_datev_export)
  • Accounting Module (account)

Business Requirements:

  • Active DATEV Unternehmen Online subscription
  • Valid DATEV user account and permissions
  • German Chart of Accounts (SKR04 or SKR03)

Important Limitations

  • Does not support pure G/L account postings (only document-based exports)
  • No master data transfer for business partners (use DATEV for master data management)
  • Certain §13b UStG cases require manual handling in DATEV system
  • Requires stable internet connection to DATEV Unternehmen Online
