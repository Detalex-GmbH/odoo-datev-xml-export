DATEV Export Base

Version 18.0.1.0

Basis-Modul für deutsche DATEV-Buchhaltungssystem-Exporte

✨ Neu: Vollständige Odoo 18.0 Kompatibilität

🎯 Überblick

Das DATEV Export Base Addon stellt die Grundfunktionalität für den Export von Buchhaltungsdaten in das deutsche DATEV-System bereit. DATEV ist eine weit verbreitete Buchhaltungssoftware in Deutschland, und dieses Modul bildet die Basis für verschiedene DATEV-Export-Funktionalitäten.

🚀 Neu in Version 18.0: Vollständige Kompatibilität mit Odoo 18.0, verbesserte Performance, erweiterte API-Funktionalitäten und modernisierte Benutzeroberfläche.
Hinweis: Dies ist ein technisches Basis-Modul. Es wird normalerweise von anderen DATEV-Export-Modulen als Abhängigkeit verwendet.

  • Berater-Nummer (1000-9999999)

📦 Installation & Abhängigkeiten

Systemvoraussetzungen (Odoo 18.0):

  • Odoo Version 18.0 oder höher
  • Python 3.10+
  • PostgreSQL 13+

Erforderliche Module:

base account l10n_de (18.0)

Installation: Über die App-Verwaltung von Odoo installieren oder via Kommandozeile: odoo -i dtx_datev_export

🛠️ Konfiguration

  1. Navigieren Sie zu Einstellungen → Buchhaltung
  2. Scrollen Sie zum Abschnitt "DATEV Export"
  3. Tragen Sie Ihre DATEV-Nummern ein:
    • Berater-Nummer: Ihre DATEV Beraternummer
    • Mandanten-Nummer: Ihre DATEV Mandantennummer
  4. Speichern Sie die Einstellungen

🔗 Verwendung als Basis-Modul

Dieses Modul dient als Grundlage für spezifische DATEV-Export-Module:

  • DATEV ASCII Export - Klassischer CSV-Export
  • DATEV XML Export - Moderne XML-Schnittstelle
  • DATEV Steuer-Export - Spezielle Steuerauswertungen
  • DATEV Konten-Export - Kontenpläne und Stammdaten

👥 Entwickler-Information

Um dieses Basis-Modul zu erweitern, fügen Sie dtx_datev_export zu Ihren Abhängigkeiten hinzu und nutzen Sie die bereitgestellten DATEV-Felder in res.company.
