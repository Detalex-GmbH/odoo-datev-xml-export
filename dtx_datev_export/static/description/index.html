DATEV Export

German Accounting Export Interface

This module provides the foundation for exporting accounting data to the German DATEV system, the leading accounting software platform used by over 500,000 accounting firms, tax advisors, and companies in Germany, Austria, and Switzerland.

Core Features

Base DATEV Infrastructure

Foundational module providing core DATEV export functionality and configuration management.

CSV Export Format

Export accounting data in CSV format compatible with DATEV systems.

Invoice & Bill Export

Export both incoming and outgoing documents with full accounting details.

Error Handling

Comprehensive error checking and validation before export.

GDPR Compliant

Data handling complies with GDPR requirements and German data protection standards.

GoBD Ready

Meets German accounting compliance standards (GoBD - Grundsätze ordnungsmäßiger Buchführung).

Technical Details

  • Configuration Management: Per-company DATEV settings and export preferences
  • Account Move Integration: Extends Odoo accounting with DATEV export capabilities
  • Export History: Track all exports with timestamps and details
  • Error Reporting: Detailed logging for troubleshooting and audit
  • State Management: Track export status and prevent duplicate submissions

About DATEV

DATEV is the leading accounting software platform used for comprehensive accounting and tax services across the DACH region (Germany, Austria, Switzerland). The system is essential for German accounting firms and companies that need to comply with local tax and accounting regulations.

System Requirements

Software Requirements:

  • Odoo 18.0 or later
  • Accounting Module (account)

Business Requirements:

  • Active DATEV subscription
  • Valid DATEV user account
  • German Chart of Accounts (SKR04 or SKR03)

Important Information

Limitations:

  • Does not support pure G/L account postings (only document-based exports)
  • No master data transfer for business partners
  • For advanced features with XML support and digitized receipt handling, install dtx_datev_export_xml
